Help

Support

Quota Otter runs on macOS 13 or later. Live quota needs an eligible ChatGPT account and in-app sign-in. The Codex helper is included. The app does not provide either subscription.

Why does the app show no quota?

Use the in-app sign-in for an eligible ChatGPT account. Open Quota Otter settings and refresh. A missing five-hour window is shown as “5h —”; the app does not substitute seven-day quota.

What do “estimated reset” and “stale” mean?

Reset times come from Codex and are estimates until a fresh query confirms updated usage. “Stale” means the last query failed; the prior result remains visible with a warning.

How do I change notifications?

Click the pet, open Settings, and change individual reminders. macOS notification permission can be changed in System Settings → Notifications. Example notices in review demo mode are explicitly labeled as demo data.

How do I import or remove a character?

In Settings choose Import character image. PNG, JPEG, and GIF files up to 10 MB are supported. The selected file is copied into local Application Support. Choose “Use built-in otter” to remove it and return to the default character.

Does the app use my code or login file?

Quota Otter's UI requests account and rate-limit status from Codex App Server. It does not read project files or prompt content. The bundled Codex helper manages its own login inside the app sandbox.

使用帮助

额度水獭支持 macOS 13 及以上版本。应用已内置 Codex 辅助程序。查看真实额度需要符合条件的 ChatGPT 账号，并在应用内登录；购买本应用不包含订阅。

  • 没有额度：在应用内登录符合条件的 ChatGPT 账号，然后刷新。若没有 5 小时窗口，菜单栏显示“5h —”，不会用 7 天额度代替。
  • 预计重置：需重新查询确认；网络错误时旧数据会标记为过期。
  • 提醒：点击水獭进入设置，可逐项开关；系统通知权限在 macOS 系统设置中管理。
  • 角色：在设置中导入 PNG、JPEG 或 GIF，文件会复制到本机；选择“恢复内置水獭”即可删除自定义角色。
  • 隐私：界面不读取代码或提示内容；内置 Codex 辅助程序在应用沙盒内管理登录。

需要帮助：提交支持请求。
